# Two The Top · Lồng đèn Mặt Trời & Vầng Trăng

Trang giới thiệu lồng đèn Trung Thu của nhóm **Two The Top** (Sun Media): mô hình 3D tương tác, chế độ trình chiếu, thành viên và hành trình làm lồng đèn.

- Xem trang: https://trakhanh.github.io/TwoTheTop/
- Chạy ở máy: `python -m http.server 5173` rồi mở http://localhost:5173

Cấu trúc:
- `index.html` — toàn bộ trang (Three.js tải từ CDN)
- `assets/` — logo Sun Media (SVG) và ảnh bìa video
- `IMG_VIDEO/` — ảnh và video quá trình làm lồng đèn
